# Phase 8.0 — Maritime Standards Register

**Audit date:** 2026-08-24
**Scope:** Every maritime measurement, constant, and navigational convention found in the OceanCalc repository as of commit `3c98f26`.

## Verification-method key

- **Web-verified [date]** — confirmed against a live source fetched during this audit (URL and access date given).
- **Established SI/legal definition** — a fixed-by-treaty or fixed-by-legal-definition constant (e.g., the international foot, the international nautical mile) that is unambiguous, non-controversial, and consistent across every Tier 1–3 source known to the auditor. Not re-fetched individually in this session; flagged separately from web-verified items per Rule 1 so the distinction is visible rather than implied.
- **UNVERIFIED** — no authoritative source was consulted or located for this specific claim during this audit. Treat as unconfirmed until checked.
