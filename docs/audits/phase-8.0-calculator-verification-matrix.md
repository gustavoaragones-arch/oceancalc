Those five standalone components are **dead code** — confirmed by static trace, not imported anywhere else in `app/` or `components/`. Their formulas were audited anyway (Rule 3 requires tracing to source, and dead code can be reactivated), but findings in dead code are labeled **[DEAD CODE]** and do not affect the live accuracy status of the calculator.
